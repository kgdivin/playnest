## Télécharger

| Système | Fichier | Pour le lancer |
|---|---|---|
| Windows | `Playnest-windows-x64.zip` | Décompresse le zip et lance `Playnest.exe`. Si Windows affiche « Windows a protégé votre ordinateur », clique sur **Informations complémentaires**, puis **Exécuter quand même**. |
| Linux | `Playnest-linux-x86_64.AppImage` | Rends le fichier exécutable (clic droit > Propriétés > Autoriser l'exécution, ou `chmod +x`), puis double-clique dessus. |
| macOS (bêta) | `Playnest-macos.dmg` | Ouvre le fichier, glisse Playnest dans Applications. Au premier lancement, fais un clic droit sur Playnest > **Ouvrir**. |

La version macOS est une bêta : elle est compilée et lancée automatiquement sur un Mac de GitHub, mais elle n'a pas encore été essayée avec de vrais émulateurs. Dis-nous comment elle se comporte chez toi.

## Nouveautés de la 3.2.0

- Playnest existe maintenant pour Linux et macOS, en plus de Windows.
- Linux : les émulateurs s'installent en un clic au format AppImage ; ceux installés par Flatpak ou par ta distribution sont reconnus, avec leurs sauvegardes.
- macOS : Playnest retrouve les émulateurs installés dans Applications. Leur installation reste manuelle.
- Les fan games Windows se lancent avec Wine sous Linux et macOS.

Playnest ne fournit ni jeux, ni clés, ni BIOS.

---

**English.** Playnest is now available for Windows (`.zip`), Linux (`.AppImage`, make it executable then run it) and macOS (`.dmg`, beta: built and launched automatically on a GitHub Mac, not yet tried with real emulators; right-click > Open on first launch). On Linux, emulators install in one click as AppImages, and Flatpak or distribution installs are detected along with their saves. On macOS, Playnest finds the emulators installed in Applications. Playnest provides no games, keys or BIOS.
